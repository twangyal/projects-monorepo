# Named complete design library — #295

The previous autosave retained one current concept. Saved designs now captures up to12 separately named, immutable complete Project JSON copies from the primary3D workspace. Names trim outer whitespace, retain literal Unicode, reject controls/unpaired surrogates, use1–80 characters, and must be unique ignoring case. Each copy obeys the existing6MiB JSON/media limits. Explicit open confirms replacement and makes one undoable concept edit. Selected backup downloads ordinary Project JSON. Confirmed deletion affects only that saved copy. Refresh never chooses or applies a different copy automatically. Closing retains the independent name field.

This is browser-local private storage, including images/artwork and applied body measurements. Browser clearing can remove it; keep downloaded JSON backups. Automatic versions, renaming/overwriting copies, cloud synchronization and cross-browser migration are outside this milestone. Existing Project schema and current-concept autosave remain unchanged.

## Ownership and persistence

A separate `clothing-studio-designs` IndexedDB database keeps small metadata and bounded payloads in separate stores. One native read/write transaction serializes duplicate/cap checks and both additions/deletions. UUID keys and `add` avoid overwriting another copy. Request, quota, rollback and queued-transaction deadlines retain existing records. Native terminal events own outcomes; successful commit is not reported before its callback. Opening/storage deadlines are nominal10seconds and browser scheduling can delay callbacks. Listing reads metadata only. Reopening verifies captured metadata, exact byte count, strict Project parsing and image admission before adoption.

Saving captures the complete applied graph before asynchronous media admission. Newer concept/name edits cannot alter that captured copy, and successful save never replaces current work or clears a newer name. Open reuses the existing beginLoad/adoptLoad/finishLoad ownership path: all raw draft groups must be resolved, and newer input/history/other loads/page departure retire a pending read. Contextual native dialog navigation retains mounted fields and returns focus on Escape. Downloads use the selected captured receipt, independently of current concept drafts.
