# Karaoke Studio local clip MVP

Issue #15, idea #6, `apps/karaoke-studio`. The actual official Spleeter two-stem model passed CPU inference in an isolated Python 3.11 runtime before implementation (10s stereo, 2.63s inference, <900MiB peak RSS). No paid services, source uploads or fabricated separation. Other completed apps are in maintenance; excluded projects remain untouched.

## Product

Import a 1–30 second WAV/MP3/FLAC/Ogg song clip, estimate vocals/backing locally, audition original/vocals/backing, paste and time lyric lines, preview a karaoke card, save/reopen local projects, and export backing WAV, timed lyrics and MP4. AI estimates the stems; users supply and synchronize lyrics. Even spacing is explicitly a draft. Separation quality is not guaranteed and automatic recognition/alignment is future work.

Use a loopback-only Python 3.11 standard-library service and a self-contained TypeScript/Vite UI. TensorFlow runs only inside a killable child process, one media job at a time. One local data directory holds at most 20 completed projects; no automatic deletion of completed projects. Service startup never downloads models. Explicit setup verifies an official pinned checkpoint archive and safe expected files. Weights and user media remain outside Git. Record code-license versus unverified separate checkpoint-license terms accurately.

## Backend contracts and ownership

`karaoke/model.py` (model/video implementer):

- `ValidationError(ValueError)`; `MAX_DURATION=30`, `MIN_DURATION=1`, `MAX_CUES=40`, `MAX_LYRIC_CHARS=5000`.
- `create_project(project_id: str, title: str, duration: float) -> dict`: fields `schemaVersion:1`, `id` (32 lowercase hex), `title` (1..100 chars), `duration` (finite 1..30), `revision:0`, `cues:[]`. Each cue `{start:float,end:float,text:str}`; ordered nonoverlapping intervals within duration, text1..240chars, <=40cues/5000chars. Plain strings only, no markup evaluation.
- `validate_project(value: object) -> dict` reconstructs safe known fields, refuses invalid types/nonfinite values/unknown schema and invalid IDs.
- `update_project(project:dict,title:str,cues:list,expected_revision:int)->dict` rejects stale revision, validates, increments revision. Service serializes writes under its lock and publishes JSON atomically.
- `render_srt(project:dict)->str`, `draft_cues(text:str,duration:float)->list[dict]` with even draft timings, reject excessive text/lines.

`karaoke/video.py` (same implementer) exports `render_card(project,active_index:int|None,output:Path,font_path:Path)->None` and `export_video(project:dict,backing:Path,output:Path,work_dir:Path,font_path:Path,cancel:threading.Event)->None`. PNG lyric cards are generated by Pillow at1280×720 using bundled DejaVuSans; FFmpeg receives fixed shell-free arguments and generated filenames, never user strings in a shell/filter. Dark background #14232f, muted #9dafbb, main #f7f5ed, accent #e4b77d. Title at y80, active text centered around y320 (wrap to1000px using font44), next cue around y540 (font26), footer at y660. No-cue card says “Instrumental break”; upcoming cue still visible. Explicit blank intervals between cues. Video24fps/H.264/AAC, audio duration preserved within a frame, <=30s; check cancellation between cards and kill/reap FFmpeg process group on cancel/timeout. Exports publish only on success. Backing is canonical44.1kHz stereo PCM16 WAV. Font assets are supplied by root.

`karaoke/pipeline.py` (runtime implementer audio_engine):

- `model_ready(model_root:Path)->bool`, `separate_clip(source:Path,output_dir:Path,model_root:Path,cancel:threading.Event,stage:Callable[[str],None])->float`. Validate WAV/MP3/FLAC/Ogg magic, max20MiB, reject unsupported playlists/protocol formats; shell-free FFmpeg with file-only protocol/format allowlists converts to bounded stereo44.1kHz PCM16 `source.wav`. Reject outside1–30seconds (not silently truncate), check finite audio and exact duration from decoded frames. Invoke dedicated offline Spleeter worker via current interpreter, limitedCPUthreads. Emit `vocals.wav` and `backing.wav` of matching duration. Stage callback values human-readable. Per-process output/time limits and kill/reap process groups; no runtime download. Worker/package imports TF only in subprocess. Model cache validated against expected files, runtime checksum checks/provenance per gate notes.
- Own setup/model scripts, ML dependency lock from successful environment and required real-model smoke script, plus pipeline/worker tests. Store generated fixtures/model outside repo and retain licensed sample attribution.

`karaoke/server.py` and `jobs.py` (server implementer):

- CLI `python -m karaoke --data-dir PATH --model-dir PATH --port 8765`, bind only127.0.0.1. Serve built `dist/` and JSON API. Reject invalid Host/Origin, no CORS, require random session token in `X-Karaoke-Token` for writes (GET session exposes it only same-origin). Limit JSON bodies64KiB, upload20MiB; reject missing/chunked lengths and invalid paths. Use generated32hex identifiers and fixed media filenames. No arbitrary local-file endpoint.
- `GET /api/session` => `{token,modelReady,maxDuration:30,maxProjects:20}`.
- `GET /api/projects` => `{projects:[Project...]}` newest first; `GET /api/projects/ID` => Project.
- `POST /api/projects` binary audio body with `X-Audio-Name` URL-encoded original name; returns202 `{job:Job}`. Model missing =>503; activejob=>409; storage cap=>409. New project appears only when complete, without replacing existing completed projects.
- Job `{id,projectId,kind:'separate'|'export',status:'running'|'complete'|'failed'|'cancelled',stage,error?:string,resultUrl?:string}`. `GET /api/jobs/ID` => `{job}`; `POST /api/jobs/ID/cancel` => `{job}`. One active bounded media job across separation/export; bound retained job records. Cleanup incomplete generated jobs, preserve completed project data. App shutdown cancels/reaps children.
- `PUT /api/projects/ID` JSON `{title,cues,revision}` => updated Project. Refuse stale versions409 and editing this project during export409; validate and atomically write `project.json`.
- `POST /api/projects/ID/export` empty JSON =>202 `{job}`; snapshot saved project, render to generated temporary output, atomically publish `video.mp4` plus revision marker only on success. `resultUrl` points to completed download. No lyrics => reject with guidance (add/timestamp lines).
- `GET /api/projects/ID/audio/{original|vocals|backing}` => respective WAV; browser audio range requests supported or valid full200 response accepted. `GET .../lyrics` => SRT attachment; `GET .../video` => MP4 attachment only when video revision matches current metadata. Serve correct lengths/types, nosniff; no original user filename in filesystem paths. Download names sanitized.
- Tests real local HTTP service with injected fake pipeline/export functions for fast endpoints, job races/cancel, request safety, limits and persistence. Fakes are test-only; production always uses real pipeline. Constructor/API injection details can be chosen by owner and documented to root for browser test setup.

Root owns frontend, font/license assets, app setup/docs/catalog/CI and integration. Frontend editable state/cue helpers validated before saves; user sees errors without losing drafts. Fixed-origin fetch with session token, explicit saved/unsaved state, generation guards for polling, playable sources and project picker. Save lyrics before export; disable edits during active export. Preview canvas uses the same1280×720 layout/font/color contract. Native HTML media playback drives cue highlighting and mark-start/end controls. No text-to-speech or automatic lyric claims.

## Verification

Fast unit/HTTP/FFmpeg tests and lint/typecheck/build; production Chromium upload→real separation→timing→save/reopen→audio/video downloads (real model available in this environment). Distinguish model smoke from fake backend tests in CI. ffprobe streams/duration and decoded video frames around cue boundaries; malicious lyric text renders literally. Invalid input, unavailable model, too-long audio, subprocess caps, cancellation, stale jobs/versions, path/Origin protection. Check offline inference and licensed vocal sample without claiming reference-stem quality. Independent review, regression fixes, durable commits/push and issue/catalog updates.
