# Reusable top-body profiles — #280

Body & drape → Saved body profiles keeps up to 20 named sets of chest, optional waist/hip girths and optional chest depth. Apply body edits first, then Save body as new profile. Selection previews measurements; Use deliberately applies them to the current top. Blank optional fields remain proportional rather than freezing derived values. Update selected can rename and replace its measurements; Delete requires a separate confirmation. Neither selection nor profile management changes the garment's design or its Undo history.

Profiles are saved only by an explicit save/update/import/delete action in this browser. A reload/new concept resets the active body; saved profiles remain available for deliberate reuse. Use follows the normal geometry, worker, comparison and captured export path, retiring old drape results. Existing unapplied body fields block Save/Update/Use instead of being overwritten. Other garment drafts remain intact.

Download body profiles makes a versioned JSON backup containing private measurements. Import accepts at most 64 KiB and 20 profiles total, appends fresh names, skips identical names/measurements, and refuses the entire import on a conflicting name. Names are unique ignoring case. A late file read loses ownership after a newer profile action, name edit, another-tab storage change or page exit. Profiles are separate from garment/project JSON and presentation exports; the garment's existing comparison receipt can still disclose the body used in that explicit comparison.

Storage reads/validation and writes must succeed before reporting a saved library. A failed quota/permission write retains the existing library and body. Corrupt stored data is never silently cleared or repaired: Download unreadable profile data preserves the original stored text for recovery. To restore after corruption, first retain that download, remove only `clothing-studio:top-body-profiles:v1` using browser site-data/developer tools, reload, then import a known valid backup. Unavailable storage requires allowing site storage and reloading; there is no server copy. Browser data clearing removes profiles. This local library is not encrypted or protected from other users of the same browser profile.

No anatomical/avatar reconstruction, material calibration or physical-fit acceptance is established. The existing approximate torso/limb geometry and XPBD material/contact limits remain. Clothing stays ACTIVE.
