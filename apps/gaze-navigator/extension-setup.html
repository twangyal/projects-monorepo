A way into the web

Your websites. Your way in.

Look at part of a website, then say what you want to do. The extension puts a context circle and a small control panel on the page you are already visiting.

Begin with pointer context and typed instructions. Add speech and webcam gaze when you are ready.

1 · One-time setup

Install in desktop Chrome

The extension currently loads from a local build. There is no Chrome Web Store installer yet. Building and loading it may need help from someone comfortable with a terminal.

This guide cannot detect or install the extension for you.

Build and load the extension
  1. Get the project source and open a terminal in the repository. Install Node.js 22.18 or newer and npm.
  2. Run these commands. The build downloads the pinned camera library; internet access is needed. 
    cd apps/gaze-navigator
npm ci
npm run build:extension
  3. In desktop Chrome 116 or newer, enter chrome://extensions in the address bar. Enable Developer mode, choose Load unpacked, and select apps/gaze-navigator/dist/extension.
  4. Find Gaze Navigator in Chrome's extensions menu. Pin it if you want the toolbar button always visible. Open a normal website before opening its popup.

For build details and current limits, read the setup and development README.

2 · Your choice

Choose where it runs

Start with Turn on for this page in the toolbar popup. By default, the navigator stops when that page changes. This first step does not require access to every website.

Stay in this tab

Stay on in this tab when pages change asks for optional website access, then continues in the tab you turned on. Turning that tab off ends its continuation.

Start on every website

Start automatically on every website asks for the same optional access and starts on ordinary pages as they load. Turn this preference off when you no longer want automatic starts.

Refusing access keeps the browsing choice off. You can keep using deliberate page-by-page activation. Chrome protects its own pages and the web store; neither access choice unlocks them.

3 · A small first task

Open one familiar link

  1. Visit an ordinary website you know. Open the toolbar popup and choose Turn on for this page. Wait for the page panel to say Ready.
  2. Move your pointer onto a familiar link, such as About or Pricing. The circle shows the nearby area; In the circle lists the controls it can currently see.
  3. In Typed instruction, enter open about (use the name of your actual link), then choose Do it. Moving into the panel keeps your last website context.
  4. If several targets match, answer the numbered question. Consequential actions need confirmation; choose Cancel when unsure. With default page-only access, the panel stops when the link loads a new page: reopen the toolbar popup and choose Turn on for this page there before trying go back. If you chose tab continuation in step 2, wait for its new panel instead.

The same instructions work in the fictional bookshop practice site, which has a built-in navigator. Its Catalog link is a useful first target: open catalog.

Keep the toolbar popup closed while using the website panel. For a keyboard command without leaving website focus, the page panel also supports Alt+Shift+G, then typing and Enter; Escape cancels. The extension's Chrome shortcut also uses this key combination for page on/off, so use the popup if Chrome captures it.

4 · At your pace

Choose how to give instructions

Pointer context and typing are ready first. Turning the panel on does not establish camera or microphone readiness.

Add spoken instructions

Choose Start listening in the page panel and allow the browser's microphone request. Look at a control, then say its action and name, such as “open catalog.” Context is captured when speech begins.

Use “pause,” “resume” or “cancel” to recover. Stop listening ends recognition. If microphone access is refused or speech is unavailable, use typed instructions and check that website's microphone permission in Chrome.

Spoken commands are currently English. Recognition uses the browser's speech service and may use its network service; the navigator does not store audio or transcripts.

Add webcam gaze

Open Tracking and settings, choose Camera, and allow the website's camera request. Keep your head comfortable and follow the 9 calibration dots with your eyes; the timed calibration needs no clicks.

After calibration the circle follows your gaze. Choose Recalibrate if it drifts, or Pointer to stop the camera. A failed camera start leaves typed and pointer control available.

The extension can reuse calibration at the same window size for up to two hours during the browser session. A resize or expired calibration requires a new one. Switching to Pointer deletes it. Face models need internet access; tiny training eye patches stay only in extension session memory, separate from website storage. Physical accuracy and intended-user usability remain unverified.

Optional smarter matching

Smarter target matching in Tracking and settings uses WaterSheep on your device for names that differ from the page's words. It downloads about 158 MB once. Start with the ordinary rule-based instructions; matching quality varies and does not replace confirmation or Cancel.

Stay in control

Pause, stop or try again

The wrong target is offered
Use Cancel before confirming. Move the circle, check its target list, and try a more specific name. Pause suspends navigation; it leaves the camera running.
You want the panel and inputs off
Open the toolbar popup and choose Turn off for this page. This also cancels startup in progress. You can turn it on again on the same page.
The popup says it cannot check or access this page
Choose Check this page again. On a protected browser page, open a normal website and reopen the popup. If a normal page still fails, reload it and try again.
A browsing choice did not save
Read the popup's feedback. Permission refusal keeps the option off; a save failure keeps your previous choice. Retry the choice when ready.

Some website controls and cross-origin frames are unreachable. This is an experimental accessibility interface; real camera/microphone reliability and evaluation with intended users are still in progress.
