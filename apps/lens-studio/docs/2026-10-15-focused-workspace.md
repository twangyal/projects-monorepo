# Focused photo workspace — #262

Lens remains ACTIVE toward useful photo simulation, depth and reconstruction. This UI milestone keeps source/result and framing prominent while retaining existing authored/estimated-depth and complete-project workflows. It does not establish real-photo depth quality, physical camera accuracy or intended-user acceptance.

## Implemented outcome

Open accepts a photo/project or original demo. Compare shows original/result, committed projection summary, essential focal/shift settings and history. Depth exposes intentional painting/selection, source zoom and reviewed local estimation; Mask exchange holds external PNG review. Project & export holds title, PNG/complete backup and saved-copy recovery, reachable even before a photo can load. Help contains detailed interpretation. Expanded workspace is a real product option and uses the same mounted controls.

Navigation changes visibility only, not editor intent, fields, history or worker authority. Text/number input events already retire older editor work; their later passive blur change events no longer retire a newly authorized read/review. Explicit Apply/Save actions retain their original guards. Unfinished gestures require finish/cancel before changing sections. Escape first handles a gesture/external-mask review, otherwise returns to comparison (Open before a photo) and restores visible focus. The read-only comparison allows phone scrolling and cannot paint labels. Rendering/export/storage and depth-estimate cancellation stay available across sections; hidden estimate completion/cancellation announces its outcome without applying a mask.
