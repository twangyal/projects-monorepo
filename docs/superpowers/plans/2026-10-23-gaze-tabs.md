Autonomous inline execution under standing owner authorization; direct main integration, no PR.

Outcome: select a website's named tab using the extension and verify its retained selection. Generic activation cannot establish that outcome. Add explicit select/choose/pick tab phrases to the deterministic interpreter, retaining existing gaze/name/ordinal clarification and consequential confirmation. Scope: ordinary single-select ancestor ARIA tablists, binary aria-selected, no browser-chrome tab control or inferred tab roles. W3C APG tabs describes manual and focus-driven activation: https://www.w3.org/WAI/ARIA/apg/patterns/tabs/ .

Capture target/group/member identity, form/root/frame ownership, label and aria-controls references, excluding mutable selection. Recheck current visibility/locks and unchanged ownership before focus/action. A selected valid target is a no-op. Focus may select automatically; drain its microtasks before deciding whether one click is necessary. The controller supplies an isCurrent ownership callback so cancel/pause/new instructions prevent a deferred click. After one website-owned click, drain microtasks and report actual single selection; never assign ARIA state or retry. No claim that selected state certifies loaded panel content or arbitrarily delayed effects.
