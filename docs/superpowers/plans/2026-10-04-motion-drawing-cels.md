# Motion #84 held drawing UI and acceptance plan

Prepared read-only from the current Motion model, main.ts, render.ts, history.ts, style.css, README, workflow/recovery browser cases, and the model owner's proposed cel APIs. No application files, builds, installs, or services were changed. Root accepted this UI/acceptance contract alongside the reviewed schema/render design; implementation may proceed within the assigned ownership boundaries.

## Product behavior

Keep Motion's existing independent layer pose animation. A drawing layer gains a sequence of held drawings (cels); image layers keep their existing fixed artwork. At any timeline frame, a drawing layer displays the last cel starting at or before that frame. Drawing at an intermediate frame edits that active cel throughout its entire held interval. Drawing must never silently insert a boundary.

Put a small **Drawings** section inside the timeline, directly below the frame slider and above a separately titled **Pose keyframes** row. On a drawing layer show an always-visible status such as **Editing drawing from frame 13 · held through frame 24**; at an interior frame add **Current frame 18. A stroke changes this drawing at frames 13–24.** These labels use the interface's existing 1-based frame numbering; stored/API frames remain 0-based. The last drawing holds through the final project frame. Keep this explanation visible on mobile; the current responsive CSS hides some pose-panel hints.

Actions: **Blank drawing at this frame**, **Duplicate held drawing at this frame**, and **Delete active drawing**. Blank inserts an empty cel; duplicate copies the currently held strokes into a detached new cel at this exact boundary. Neither changes pose keys or other layers. Both actions are disabled at an occupied boundary and at the cel limit, with visible explanation **A drawing already starts here; edit it or choose another frame.** There is no implicit replacement of an existing drawing. Drawing directly remains available at an occupied boundary, including frame 1.

Each cel has a native button labeled **Drawing from frame N, held through frame M**. Clicking it seeks to its first frame and pauses playback. Mark the active held cel with aria-pressed even while seeking inside its interval; distinguish the current playhead label from the cel start. Do not create a second independently selected cel state that could disagree with the layer/frame used for drawing. Delete removes the active non-first cel and lets the preceding cel hold through the removed interval. Explain that effect before the action in its description, announce the new interval afterwards, and make it one undoable edit. The first cel cannot be deleted; its disabled action has a visible reason. Deleting a whole layer keeps existing Undo semantics.

For an image layer show **Imported artwork stays the same; animate its pose.** Hide or disable drawing-only actions with that explanation. No unsupported cel operation should quietly become a pose operation.

Onion skin is optional and should be omitted from this first milestone unless root explicitly includes it. It is not necessary for the usable blank/duplicate/hold workflow. If included, only previous/next cel artwork for the selected drawing layer is an editor overlay, never persisted, exported, shown during playback, or used in layer bounds. Its rendering must not alter ordinary canvas PNG export.

## Candidate DOM contract

- #drawing-timeline: region labeled **Selected layer drawings**.
- #drawing-status: persistent readable exposure description; avoid announcing it every animation frame.
- #drawing-cels: native buttons with data-cel-frame containing the stored frame, aria-pressed for the active held cel.
- #add-blank-cel: **Blank drawing at this frame**.
- #duplicate-cel: **Duplicate held drawing at this frame**.
- #delete-cel: **Delete active drawing**.
- #drawing-action-hint: occupied boundary, protected first cel, or capacity explanation; referenced by relevant buttons with aria-describedby.
- Existing #keys remains pose-only and gains an explicit **Pose keyframes** heading/region label.
- #pose-draft-status and #discard-pose-edits: **Discard pose edits**; names may use a shared editor-draft status/control if the final contract chooses one.

Use native buttons and the existing native Timeline frame range, rather than a custom grid with ambiguous arrow-key behavior. All cel buttons participate in ordinary Tab order and activate with Enter/Space. Keep selection focus stable when rerendering the list; after deleting a cel move focus to the preceding active cel button. New and duplicate actions keep focus on their action button. At most 24 cel buttons per selected layer may wrap rather than squeeze into unreadable ticks.

Mobile: cel action buttons have at least 44 CSS pixel hit targets, wrap within the timeline, and retain full labels. No page-wide horizontal overflow at 390px. Keep canvas touch-action:none locally; timeline controls and page remain scrollable. Pose diamonds and cel buttons must be distinguishable by text, not just color/shape.

## Raw drafts and gesture ownership

The current poseFields() rewrites every numeric input on seek/play/refresh; current invalid numeric change falls through refresh() and loses the raw draft. Add an explicit draft admission guard before cel navigation/mutation, layer selection, seek/play, Undo/Redo, duration change, import/reset, and recovery publication. Draft state is tied to the layer and frame it edits. Either successful existing change/Set keyframe commits all admitted pose fields once, or the user explicitly discards them; no cel action performs an accidental numeric commit. Keep compatibility with valid change-on-blur and Set keyframe workflows. Finite in-range numeric values are valid even when stepMismatch is true. Preserve exact entered spelling while unsent, including an empty invalid field. For preservation of arbitrary partial numeric text beyond native number.value semantics, use text/inputmode=decimal fields; otherwise explicitly limit the guarantee to the browser-exposed value. Do not round canonical pose values to three decimals when restoring a draft or committing another field.

Keep project/layer name behavior compatible: successful input commits remain edits; an empty/invalid pending name is retained and blocks actions that would repopulate its field. Clear, visible Apply/Discard guidance replaces silent refresh loss. Color/brush are tool preferences and do not become document drafts. Save project file may export committed work with clear **Unapplied edits are not included** status; do not serialize raw invalid fields.

A pointer gesture freezes base project, layer ID, active cel start, playhead, pose, viewport dimensions/DPR, and canvas rect before its preview. Draw modifies only that exact cel in a detached candidate; Move modifies only the pose key at the frozen playhead. Validate aggregate limits across all retained cels. A completed stroke (including a single dot) or moved pose is one history entry and one save scheduling event. A no-op Move must not clear Redo. Rejection or cancellation leaves committed state, saved data, Redo, and all unrelated raw fields unchanged.

Centralize cancellation for pointercancel, lost capture, Escape, blur, hidden document, pagehide, resize/changed canvas geometry, and replaced operation. Clear owned gesture before releasing capture to prevent a second completion. Synchronously compare the frozen geometry before pointer preview AND pointerup: delayed ResizeObserver/window resize delivery must not allow a resized stale gesture to commit. Escape first cancels an active gesture; it does not implicitly discard unrelated editor drafts. Ended stale callbacks cannot commit to another cel, layer, project, or frame. Editor controls remain locked during the gesture; export/backup cannot capture the preview.

## Duration shortening and recovery

Before shortening, obtain an exact model-compatible loss summary for all layers: number of cels starting at/after the new frameCount and pose keys at/after it (synthetic retained endpoint pose is not a loss). If neither is removed, resize without destructive consent. Otherwise native confirmation states the old/new durations and both removal counts, explains Undo, and offers Cancel. A dismissed confirmation preserves project/history/Redo, playhead, raw fields, and duration selector value. An accepted confirmation commits exactly one model candidate using explicit discardLater:true. Check the captured project generation and raw-draft readiness again before publication; no old confirmation applies to newer work. Extension holds final drawing and pose without inventing cels. The model must preserve the evaluated pose at the new endpoint, as the existing transform timeline does.

Preserve #48 recovery behavior in full: absent and unreadable/present-corrupt records are distinct; bad old or new schema data is never treated as an empty project. Cel edits, history, exports, and imports in protected mode cannot overwrite the preserved record. Raw download remains the exact original read record, including schema1 and unknown fields; ordinary backup is the validated current schema2 document. A valid schema1 record migrates in memory to one frame0 cel per drawing layer, with original stroke/pose values preserved, without rewriting durable storage merely by loading. The first successful actual edit/save may publish schema2 atomically.

Retry stays editable as today. New raw input, seek/layer/cel intent, gesture start, committed edit, Undo/Redo, import/reset, or pagehide invalidates its publication token; late decoded bitmaps are released. A completed retry asks before replacing changed memory work. A draft guard applies before confirmation/publication, not merely a commit-generation check. Retry failure/cancel/stale completion preserves cel graph, history, raw fields, and original record. Startup remains locked until restoration completes.

## Model seam agreed in principle with audio_engine

DrawingLayer schema2: {id,name,kind:'drawing',cels:[{frame,strokes}],keys}; first frame0 mandatory, increasing integer boundaries < frameCount, at most24 cels/layer. Existing 100 strokes and10,000 points apply globally across ALL cels, without dedup discount. API proposals: addBlankDrawingCel(project,layerId,frame), duplicateDrawingCel(project,layerId,frame), replaceDrawingCelStrokes(project,layerId,celFrame,strokes), removeDrawingCel(project,layerId,celFrame), evaluateDrawingCel(layer,finiteFrame), resizeTimeline(project,newCount,{discardLater?:boolean}). Root/model owner freezes exact signatures. Add/duplicate reject occupied boundaries; remove rejects frame0; evaluator returns detached held content. Drawing uses exact existing cel replacement, never add-on-pointerdown. UI should use an exported pure resize-loss helper or the same explicit counts frozen by the model contract, so dialogs cannot diverge from model discard admission.

## Native acceptance to author before implementation outcomes

1. Real native drawing: draw red at frame1, duplicate at frame7, add green only to later held cel, blank at frame13, then draw blue there. Independently inspect committed JSON and actual canvas pixels at frames6/7/12/13/last (display numbering), proving exact boundaries and that editing an interior held interval changes only that interval. Include image and transform animation coexistence.
2. Delete non-first cel extends preceding hold; protected first removal and occupied blank/duplicate refuse without state changes. Undo/Redo exactly restores boundaries and detached strokes. A failed aggregate-limit duplicate and a no-op/rejected action preserve an existing Redo branch.
3. Actual downloaded PNG equals the selected cel frame with no ghost overlay. Independently decode all actual GIF frames/delays: abrupt cel changes occur at the exact frame, pose still interpolates, final hold persists, total duration remains correct. Compare decoded palette colors with declared quantization tolerance, not full-color byte equality.
4. Literal genuine schema1 fixture opens to equivalent pixels and schema2 backup; native IDB restore does not rewrite the original until an actual successful edit. Schema2 backup reopens exactly and a real browser restart restores all cels. Broken schema2/image and read/write/transaction-abort failures keep durable recovery data intact and memory exportable.
5. Native pointercancel/lost capture, Escape, blur, hidden/pagehide, and delayed-resize delivery all discard previews with no history/save. Controlled lifecycle delivery is labeled; do not claim genuine BFCache or physical touch from synthetic events. A subsequent fresh gesture remains usable.
6. Raw empty/invalid/off-grid pose spelling survives attempted cel navigation, shortening, recovery completion, redraw, and rejected action; explicit discard or valid apply unlocks. A delayed real image decode during recovery/import cannot overwrite a later cel/draft edit and its bitmap is closed.
7. Shortening fixture contains future cels and keys in multiple layers. Exact loss counts, dismiss preserves all data, accept removes only agreed future starts and retains endpoint pose/held artwork; one Undo returns exact original timeline. Extension does not clone artwork or consume cel budget.
8. Native keyboard frame range/cel button navigation, focus after delete, Space playback from canvas, Undo shortcuts outside inputs, and 390px viewport containment/full hit targets. Record zero page errors/external requests, retained desktop/mobile screenshots, and honest physical-device limitation.

Useful owner boundaries: model/history pure admission + migration tests; independent pixel/export oracle fixtures; UI owns draft/gesture/recovery generation guards; browser owner uses only literal original fixtures/native controls rather than importing production evaluators to derive expectations. No general DAW, backend, AI model, frame drag retiming, onion export, or new asset registry is needed.
