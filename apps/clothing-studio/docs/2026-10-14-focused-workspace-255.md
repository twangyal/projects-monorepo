# 3D-first contextual workspace — #255

## Outcome and scope

The owner's 2026-10-14 feedback prioritizes the editable 3D garment over an all-in-one form page. This milestone reorganizes the existing mounted application: primary viewing/part selection and six task sections stay around the garment, while tech pack, range/costing, concept sketch and skirt construction use native secondary dialogs. Native modal behavior and heading/return focus, close buttons and Escape support keyboard recovery. A real optional expanded view exposes existing tools for cross-tool workflows; it is not the default and does not alter project data.

Existing controls and their handlers are moved, not cloned or remounted. Only section visibility changes; raw fields, grouped drafts, asset admission, worker state, history and captured exports retain their existing owners. View-only navigation is exempt from the product image-decode retirement listener, while actual edits still retire stale image work. Shared live feedback is moved into the active section/dialog and restored at its original anchor on close. Body/drape remains discoverable, with the original solver/material/body approximation limits intact.
