# Artwork rotation — #254

The Fabra-style workflow needs graphic placement control beyond upright logos. Rotation extends the existing front/back artwork placement group, without a new subsystem. Designers stage an angle from −180 to 180 degrees, with positive clockwise rotation as seen from outside, and Apply it with width/position as one undoable saved design edit. The centre remains where the unrotated placement put it; artwork clips to its supporting garment. Tech-pack print width/height remain the original print dimensions, with a separate angle in the placement description.

The optional `rotation` field preserves legacy artwork exactly when omitted; explicit values must be finite numbers in range. Existing project/backup validation includes this admission. The inspector’s existing draft group preserves raw rotation across selection/redraw and requires Apply/Discard at existing replacement/history boundaries. The shared decal creation path rotates before mapping onto settled cloth, so shell/drape, PNG/GLB and printable tech-pack render snapshots use the same placement. No asset, worker, resource guard, schema-version, dependency or security change.
